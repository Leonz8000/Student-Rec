# Student-Rec
Student Records Management System

This system is designed to manage and store student records using firestore database. It allows users to easily add and save students information through an input form. Once a student record is stored in the database, the user can view, edit, or delete the information whenever necessary.

The system als0 includes a search funcionality located below the input form. Users can search for a specific student record by entering relevant information, making it easier to find and update a student's details without manually checking through all the records.

Overall, the system provides a simple and organized way to add, manage, search, update, and delete student records, helping make student information management faster and more convenient.
